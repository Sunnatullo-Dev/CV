# DevPort

Professional portfolio and CV builder for developers. The app combines a guided profile flow, GitHub project import, live portfolio templates, and AI-assisted CV copy.

## Local Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Create `.env.local` and add:
   ```bash
   GEMINI_API_KEY=your_api_key
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open:
   ```text
   http://localhost:3000
   ```

## Checks

npm run lint
npm run build
